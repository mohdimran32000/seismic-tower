# The Tower and El Centro

A fictional 20-storey concrete tower, shaken with the real 1940 El Centro earthquake until it collapses. The numbers behind the video: design, earthquake records, step-by-step results and checks.

Live page: https://mohdimran32000.github.io/seismic-tower/

A simplified teaching model, not a design check. Analysis: OpenSees. 3D: Blender.
